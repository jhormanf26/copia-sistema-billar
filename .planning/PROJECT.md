# PROYECTO-BILLAR

## Descripción
Sistema de gestión para billares, desarrollado con Laravel. El proyecto busca centralizar la administración de mesas, ventas y socios.

## Tecnologías
- **Backend:** Laravel (PHP)
- **Frontend:** Blade, TailwindCSS, Vite
- **Base de Datos:** MySQL (XAMPP -> Migrando a Oracle Cloud Ubuntu)
- **Infraestructura:** Oracle Cloud Infrastructure (OCI) con Ubuntu

## Objetivos del Proyecto
- Gestión eficiente de tiempos de juego en mesas de billar.
- Control de inventario y ventas de productos.
- Implementación de un sistema robusto y escalable en la nube.
